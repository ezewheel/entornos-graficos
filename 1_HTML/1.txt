1. HTML (HyperText Markup Language o Lenguaje para el Formato de Documentos de Hipertexto) es el lenguaje universal que permite que cualquier computadora del mundo pueda entender y mostrar información en la web. Fue desarrollado en los años 90 por Tim Berners-Lee mientras estaba en el CERN. Las diferentes versiones fueron HTML 1.0, HTML 2.0, HTML 3.0, HTML 3.2, HTML 4.0, HTML 4.01 y la versión actual HTML 5.
2. Los principios recomendados por la W3C son separar estructura y presentación, considerar la accesibilidad universal a la Web y ayudar a los agentes de usuario con la representación incremental.
3. Un elemento o atributo se considera obsoleto o desaprobado cuando existen hojas de estilo mecanismos de presentación más potentes.
4. Un DTD (Document Type Definition) es el documento que define la sintaxis y las reglas del lenguaje, como qué etiquetas existen, cuáles pueden ir dentro de otras, etc.
5. Son datos que no se muestran directamente como contenido de la página, sino que ayudan a los motores de búsqueda a indexar, definen el idioma natural, la dirección del texto o la codificación de caracteres.
